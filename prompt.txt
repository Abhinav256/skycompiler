# AI Prompt — Design a World-Class Online Compiler (Sky Blue Cloud Theme)

Design a **modern, premium, world-class online compiler and code editor** for an educational platform. The interface should rival or surpass **LeetCode, HackerRank, Replit, VS Code Web, and CodeSandbox** in usability while maintaining a clean, beginner-friendly experience.

## Theme & Visual Style

Create a futuristic, minimal, and elegant interface inspired by **cloud computing**.

### Color Palette

* Primary: Sky Blue (#38BDF8)
* Secondary: Azure Blue (#0EA5E9)
* Accent: White (#FFFFFF)
* Background: Soft Sky Gradient
* Light Cloud Shadows
* Frosted Glass (Glassmorphism)
* Rounded Corners (16–20px)
* Soft Blue Glow Effects
* Subtle Floating Cloud Animations

The UI should feel like **coding above the clouds**, giving users the sensation of programming in an anti-gravity environment.

Avoid dark or hacker-style themes by default. Prioritize clarity, professionalism, and comfort for long coding sessions.

# AI Prompt — Build the Backend Logic for a Professional Multi-Language Online Compiler

Design the complete backend architecture for an enterprise-grade online compiler similar to LeetCode, HackerRank, Replit, and CodeChef. The system must be secure, scalable, and support multiple programming languages.

---

```

↓

↓

↓

Validate Request

↓

Capture Output

↓

↓

↓

↓

↓

Return Result

↓

Display Output
```

# Step 5

Compile

Skip compilation.

```

```

```

```

# Step 9

Timeout Protection

If execution exceeds

2–5 seconds

# Step 10

Memory Limit

Example

256 MB

Terminate programs exceeding the limit.

---

# Step 11

Security

Never execute code directly on the host system.

Each execution must run inside an isolated Docker container.

Container

↓

Compile

↓

Execute

↓

Destroy

No execution should have access to the host filesystem, network, or other users' code.

---

# Step 12

Delete Temporary Files

After execution:

```
Delete

temp/

↓

Delete Container

↓

Release Memory
```

Never leave source code on the server.
